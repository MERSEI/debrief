# Debrief

Записывает рабочий созвон на Windows **двумя отдельными дорожками** и превращает
его в структурированный протокол встречи: договорённости, обязательства сторон,
открытые вопросы, красные флаги, цитаты с таймкодами.

Работает без бота-участника в конференции: звук берётся с самой машины, поэтому
Zoom, Meet, Telegram и Discord одинаково безразличны.

## Почему две дорожки

Обычный подход пишет один смешанный поток и затем пытается разделить голоса
диаризацией. Это вероятностный шаг, и он ошибается ровно там, где дороже всего —
на перебиваниях и коротких репликах.

Debrief пишет микрофон и системный вывод (WASAPI loopback) в два файла. Дорожка
микрофона — это всегда «я», дорожка loopback — всегда «собеседник». Спикер
известен точно, без модели и без порогов похожести голосов.

Взамен появляется эхо: если звук идёт в колонки, микрофон переспрашивает
собеседника, и одна фраза попадает в обе дорожки. Это лечится в
`debrief/transcript.py` — сегмент считается эхом, только если он одновременно
перекрыт по времени и текстуально похож на оригинал. Оба условия обязательны:
перекрытие без похожести — это обычное перебивание, и терять его нельзя.

## Установка

```bash
pip install -e ".[capture,dev]"
cp .env.example .env   # заполнить ANTHROPIC_API_KEY
```

Требуется Python 3.11+ и Windows для захвата. Разбор уже записанных дорожек
(`debrief process`) работает на любой ОС.

`faster-whisper` скачивает модель при первом запуске: `large-v3` — около 3 ГБ.
На машине без GPU начните с `DEBRIEF_WHISPER_MODEL=small` и
`DEBRIEF_WHISPER_COMPUTE_TYPE=int8`.

## Использование

```bash
debrief devices                          # проверить, что именно будет записано
debrief record --hint "собес на Python"  # запись; Ctrl+C — стоп и разбор
debrief process recordings/сессия.mic.wav
```

`--hint` заметно улучшает разбор: без него модель не знает, чья сторона какая,
и трактует разговор нейтральнее, чем нужно.

Начинайте с `debrief devices`. Если loopback не нашёлся, звук идёт мимо WASAPI —
разбираться нужно там, а не в записи.

## Как устроено

```
запись           debrief/audio/    два потока WASAPI -> два WAV с общим нулём времени
распознавание    debrief/stt/      faster-whisper по каждой дорожке отдельно
склейка          debrief/transcript.py  эхо-фильтр, слияние по общей оси времени
разбор           debrief/summarize.py   Claude + Pydantic-схема ответа
выдача           debrief/sinks/    Markdown в Obsidian, карточка в Telegram
```

Схема протокола валидируется на стороне API (`client.messages.parse`), а не
парсингом markdown из текста ответа. Промпт запрещает достраивать смысл: пустой
раздел — нормальный результат, выдуманный — брак.

## Ограничения

- Захват только Windows: WASAPI loopback — механизм этой ОС.
- Запись разговора со второй стороной регулируется законом и различается по
  юрисдикциям. Для личных заметок это одно, для продукта — нужен явный флоу
  уведомления собеседника.
- Разбор стоит денег: примерно цена одного запроса Claude на созвон.
  Распознавание — локальное и бесплатное.
